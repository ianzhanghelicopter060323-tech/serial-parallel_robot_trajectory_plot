# 机器人学作业，串并联2DOF机器人轨迹绘制

本项目为机器人学课程作业，用于串联与并联二自由度（2DOF）机器人的轨迹绘制。

程序使用 Python、NumPy 和 Matplotlib，根据给定的关节角度计算末端位置，并绘制末端轨迹。图中标注起点和终点，使用等比例坐标轴，最终以 300 dpi 保存为 PNG 图片。

## 目录结构

```text
.
├── README.md
├── src/
│   ├── plot_serial.py       # 串联二连杆机器人轨迹
│   └── plot_parallel.py     # 并联机器人两种装配分支的轨迹
└── output/                 # 轨迹图片，运行时自动创建
```

当前脚本的输出文件为 `trajectory_serial.png` 和 `trajectory_parallel.png`。目录中已有的 `trajectory.png`、`trajectory_paralell_1.png` 和 `trajectory_paralell_2.png` 不属于当前脚本的输出文件名。

## 环境与运行

需要 Python 3，并安装以下依赖：

```bash
python3 -m pip install numpy matplotlib
```

在工程根目录分别运行：

```bash
# 绘制串联机器人轨迹
python3 src/plot_serial.py

# 绘制并联机器人轨迹
python3 src/plot_parallel.py
```

每个脚本都会先保存图片、打印保存路径，然后显示绘图窗口。关闭窗口后程序结束。输出路径根据脚本所在位置确定，因此从其他目录运行时，图片仍会保存到本工程的 `output/` 目录。

在没有图形界面的环境中，可使用非交互式后端，只生成图片：

```bash
MPLBACKEND=Agg python3 src/plot_serial.py
MPLBACKEND=Agg python3 src/plot_parallel.py
```

再次运行会覆盖对应的同名图片。目前没有命令行参数，修改机器人尺寸或输入角度时，需要编辑对应脚本中的 `plot_trajec()` 函数。

## 串联机器人

`src/plot_serial.py` 使用平面二连杆模型，其中第二关节角为第二杆相对第一杆的转角。末端位置由正运动学公式计算：

```text
x = l1 · cos(θ1) + l2 · cos(θ1 + θ2)
y = l1 · sin(θ1) + l2 · sin(θ1 + θ2)
```

默认参数如下：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `l1` | 10 | 第一杆长度 |
| `l2` | 5 | 第二杆长度 |
| `theta_1` | −π/2 到 π/2，1001 个采样点 | 第一关节角 |
| `theta_2` | −π/2 到 π/2，1001 个采样点 | 第二关节角 |

两组角度逐点配对，默认运动满足 `theta_1 = theta_2`，得到一条末端轨迹，并非遍历所有关节角组合得到的完整工作空间。脚本中的角度单位为弧度；串联脚本未指定长度单位，末端坐标与输入杆长使用相同单位。

输出图片：`output/trajectory_serial.png`。

## 并联机器人

`src/plot_parallel.py` 使用平面五杆并联机构的几何关系计算末端位置。两个固定铰点分别位于 `(0, 0)` 和 `(l3, 0)`；主动杆长度为 `m`、`n`，连接主动杆端点与末端的两根杆长度为 `l1`、`l2`。

默认长度单位为毫米，参数如下：

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `m`、`n` | 各 100 mm | 两根主动杆长度 |
| `l1`、`l2` | 各 300 mm | 两根末端连接杆长度 |
| `l3` | 300 mm | 两个固定铰点的间距 |
| `t` | 0 到 2π，500 个采样点 | 描述一周期运动的参数 |

输入角度随参数 `t` 变化：

```text
θ(t) = 90° + 60° · sin(t)
φ(t) = 90° + 60° · cos(t)
```

两角均在 30° 到 150° 范围内变化，代码使用 `np.deg2rad()` 转为弧度后进行计算。这里的 `t` 是轨迹参数，代码未规定实际运动时间或速度。

两根主动杆的端点为：

```text
A = (m · cos(θ), m · sin(θ))
B = (l3 − n · cos(φ), n · sin(φ))
```

末端是以 A、B 为圆心、以 `l1`、`l2` 为半径的两圆交点。令 `d = B − A`，则：

```text
s = |d|
a = (l1² − l2² + s²) / (2s)
h = sqrt(l1² − a²)
P± = A + (a/s) · d ± (h/s) · (−dy, dx)
```

代码同时绘制 `σ = +1` 和 `σ = −1` 两种装配分支的轨迹。由于输入覆盖完整周期，轨迹起终点重合，因此使用绿色空心圆与红色叉号区分两者。

输出图片：`output/trajectory_parallel.png`，两条轨迹保存在同一张图中。

## 参数修改与适用范围

- 调整杆长、关节角函数或 `np.linspace()` 的采样点数，可以生成不同的轨迹。
- 并联机构计算要求 `s > 0` 且 `|l1 − l2| ≤ s ≤ l1 + l2`，以保证两圆有交点。当前代码没有对不可达位置或退化情况进行保护，修改参数时需要检查这些条件，否则可能产生除零或平方根无效值。
- 本工程用于运动学轨迹绘图，未实现动力学分析、碰撞检测、机器人控制或轨迹动画。所绘曲线表示给定关节运动下的末端位置，不代表完整工作空间。
